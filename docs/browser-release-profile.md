# Browser native release profile

The Browser registration binds source fefce61f9cfc706258047cfb96bfe43ba94ffcaf,
its ten owning release/image/probe helpers and a private, content-addressed
Browser SIF qualified on compute-03. The image layers pinned Playwright 1.65.1,
Chromium 158.0.8127.18 and native browser libraries on the existing E846 base.

All three complete retained suites passed 249 tests and two existing optional
peer skips per Python version, using the original 32-worker policy and deadlines.
The separate same-source build verified 190 wheel payloads and 276 sdist source
files. A fresh normal wheel installation resolved 31 compatible packages and
passed the real offline fill/value/input/change/missing-selector probe inside the
finished SIF. A changed wheel refused before installation or browser launch.
Actual user-namespace execution and a clean runtime trace verified read-only
zstd SquashFS through squashfuse_ll.

The build operation must run the leaf's fresh-wheel probe after the complete
artifact build and before upload. The dispatcher supplies the recorded source
and tag; the helper verifies the archive proof and clears source PYTHONPATH.
The profile selects its fixed approved image path on compute-03, without changing
other profiles' repository-variable locators or broadening host admission.
Writer, IO and Scholar retain their independent source closures, runtime
qualification records, worker policies and operation limits. Their common image
and runtime byte constants are shared without changing the resulting plans.

The first generic-image browser launch failed on missing native libraries.
An initial layer failed because its test inherited a host-only TMPDIR; the
recipe now uses container scratch. Gzip compression then exceeded the original
300-second build bound. The separately built zstd-level3 candidate completed in
84 seconds under the same two-CPU/12-GiB budget, with the real launch test enabled.
These failed candidates remain failed evidence and are not registration inputs.

This registration grants neither a release tag nor publication. Browser source
coverage remains 26%; the offline probe does not verify live-site authentication,
complete popup behavior or physical mobile browsers. Protected-main/tag checks,
publisher trust and an unused release version remain separate requirements.
